## How to use

1. Pick the brand the user named, or suggest 2-3 that fit the brief if none was named.
2. Read only that file: `references/<brand>.md`. Don't load several at once — they're long.
3. Apply its tokens (colors, type scale, radii, spacing, shadows) and component rules to the code you write.
4. If the user wants it in the project, copy it to the project root as `DESIGN.md`.
5. These are "inspired by" analyses: don't copy logos, trademarks or brand names into the UI — reuse the visual language only.
